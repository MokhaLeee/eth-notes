参考教程: https://wiki.neardi.net/zh-Hans/docs/neardi-wifi/wifi-adapt/adaptation/

menuconfig 新增配置
```bash
# common
CONFIG_SEEKWAVE_BSP_DRIVERS_V20=y
CONFIG_SKW_USB=m
CONFIG_SWT6652_LOG_DEBUG=y
CONFIG_SEEKWAVE_PLD_RELEASE=y

# wifi
CONFIG_WIRELESS=y
CONFIG_WLAN=y
CONFIG_CFG80211=m
CONFIG_WLAN_VENDOR_SWT6652=m

# bt
CONFIG_BT=y
CONFIG_MMC=y
CONFIG_SKW_BT=m
```

Rootfs 需要新增固件
- SWT6652_DRAM_USB.bin
- SWT6652_IRAM_USB.bin
- SEEKWAVE_NV_SWT6652_SHARE.bin
